# Skills

`grill-me` and `grilling` come from [mattpocock/skills](https://github.com/mattpocock/skills)
(commit 4ae2317, MIT, see `LICENSE-mattpocock-skills`).

- `/grill-me`: user-only entry point (`disable-model-invocation: true`) that calls `grilling`.
- `grilling`: the real skill. It interviews you in rounds about a plan or design. Claude can also invoke it on its own when you say things like "grill me".
